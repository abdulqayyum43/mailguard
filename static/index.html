What we analyze

Complete Email Security Coverage

Every critical email security control checked and scored in a single API call.

📋

SPF Analysis

Parses Sender Policy Framework records, validates mechanisms, counts DNS lookups and detects -all enforcement or missing records.

🛡

DMARC Enforcement

Checks policy (none/quarantine/reject), pct, rua reporting tags, and overall enforcement posture. Maps to PCI-DSS and SOC 2 controls.

🔑

DKIM Discovery

Probes 38 common selectors to find active DKIM keys. Validates key strength — flags RSA keys below 1024 bits as weak.

🔒

MTA-STS Policy

Checks the MTA-STS DNS record and fetches the policy file. Validates mode (enforce/testing/none) and reports missing configuration.

📨

MX & STARTTLS

Resolves all MX records, connects to each mail server and verifies STARTTLS support, TLS version, and cipher strength.

🚫

Blacklist Checking

Checks all mail server IPs against 5 major RBLs (Spamhaus, SpamCop, SORBS, Barracuda, UCEPROTECT) in parallel.

🎭

Spoofability Score

Combines SPF, DKIM, and DMARC findings into a HIGH/MEDIUM/LOW spoofability risk — tells you if your domain can be impersonated.

📄

PDF & Compliance Reports

Download branded PDF reports or generate compliance assessments mapped to PCI-DSS v4.0, SOC 2 Type II, and ISO/IEC 27001:2022.

🔔

Monitoring & Alerts

Schedule recurring scans and receive Slack, email, or webhook alerts when a domain gets blacklisted or its spoofability changes.

with MailGuardClient("mailg-pro-xxxx") as client:
    result = client.analyze("example.com")
    print(result["grade"], result["score"])  # A+  100

    # Save PDF report
    client.save_pdf_report("example.com", "report.pdf")

    # Generate SOC 2 compliance report
    client.save_compliance_report("example.com", "soc2", "soc2.pdf")
